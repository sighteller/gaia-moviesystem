# Revisione delle citazioni

La casella Revisionata è salvata insieme al testo, personaggio, fonte e data di revisione nel browser. Il pulsante Segna le mie citazioni salvate come revisionate aggiorna solo le modifiche già salvate, senza alterarne il testo. Nessuna proposta dell'assistente viene approvata automaticamente. Modificare testo, personaggio o fonte deseleziona la revisione; serve Salva per confermare il nuovo stato. Esporta include reviewed e reviewed_at.
